## 新增

- 新增桌宠最大帧率设置，可在 30～120 FPS 之间调整，保存后立即生效。
- 新增单实例保护：重复启动时第二个实例会退出并唤起已有控制面板。

## 优化

- Max Tokens 改为程序内部管理，默认从 300 tokens 开始，回复被截断时自动翻倍重试，最高 4096。
- Temperature 增加 0～2 范围校验，避免保存非法配置。
- 随机待机动作间隔调整为 5～20 秒。
- 重构六种人格的 system prompt，统一自我认知、短句发言规则和场景反应，减少重复内容。
- 旧配置中的 `maxTokens` 字段会自动删除；新配置使用 `maxFps`。

## 说明

- 本次更新不改变现有 API Key、人格选择和桌宠位置配置。
- 当前 Windows 安装包未配置商业代码签名，首次运行时可能出现 SmartScreen「未知发布者」提示。
