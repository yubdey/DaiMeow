## 新增与优化

- AI 请求开始按服务商适配思考模式参数，回复被 Token 截断时会自动提高预算重试，最多到 4096。
- 截图间隔默认调整为 15 秒，可调范围调整为 5～30 秒。
- Max Tokens 默认值调整为 300，可调范围为 50～4096。
- 六种人格名称和提示词统一为「喵」，并精简不必要的人格颜色配置。
- 生活词条改为按时段使用比例判定，夜间和早间时段划分更明确；已解锁词条按首次解锁时间排序。
- 调整「灵光一闪」和「思考中」动作的挥手、眼珠与节奏。
- 打包流程新增旧版本产物自动清理，避免 `release/` 长期堆积多个版本的安装包。

## 说明

- 本次更新不改变用户现有 API Key、人格选择和桌宠位置配置。
- Ollama 已在上个版本移除；旧配置仍会自动迁移到云端 API 模式。
- 当前 Windows 安装包未配置商业代码签名，首次运行时可能出现 SmartScreen「未知发布者」提示。
