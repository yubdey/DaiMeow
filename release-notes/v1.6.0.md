## 修复

- 修复 AI 回复截断重试预算与文档不一致的问题：现在最多尝试 3 次，输出预算上限为 900 tokens。
- 停止运行时会取消进行中的 AI 请求，避免停止后继续消耗额度或显示迟到回复。
- 修复停止后本次运行时间继续增长的问题。
- 修复手柄 XInput 与 Chromium Gamepad API 同时工作时互相覆盖视线输入的问题。

## 优化

- 控制面板关闭后销毁窗口以释放资源，托盘点击时按需重新创建。
- 加强统计文件字段校验，异常的字符串、负数和非有限数值不会进入累计统计。
- 优化窄窗口下的人格卡片布局，最小宽度下改为两列显示。

## 安全与维护

- 限制控制面板可调用的 IPC invoke channel，未知 channel 会被拒绝。
- 动作预览服务器的路径检查会解析 symlink / junction，阻止访问项目目录外的文件。
- GitHub Actions 在构建前增加自动化测试步骤。

## 说明

- 本次更新不改变 API Key、人格选择和桌宠位置配置。
- 当前 Windows 安装包未配置商业代码签名，首次运行时可能出现 SmartScreen「未知发布者」提示。
