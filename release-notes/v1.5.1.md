## 修复

- 改进手柄右摇杆控制兼容性：XInput 现在会检查前 4 个手柄槽，并新增 Chromium Gamepad API 兼容回退。
- 修复 PowerShell 轮询输出可能被缓冲，导致手柄摇杆输入无法及时更新视线的问题。
- 修复非 Xbox/XInput 手柄被 Chromium 探测到、但 XInput 无法读取右摇杆时完全不响应的问题。

## 说明

- 手柄控制仍由 `gamepadEnabled` 控制；请确认该配置为 `true` 并重启呆喵。
- 无法被 Chromium 识别的非 XInput 手柄，可通过 Steam Input 映射成 Xbox 控制器。
- 当前 Windows 安装包未配置商业代码签名，首次运行时可能出现 SmartScreen「未知发布者」提示。
