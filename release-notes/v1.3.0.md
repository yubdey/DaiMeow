## 新增

- 新增 `hello`（Hello）、`drool`（流口水）、`question`（问号）、`idea`（灵光一闪）和 `thinking`（思考中）动作。
- 新增动作定义表和动作控制器，补充动作池、点击冷却、站坐状态机测试。

## 优化

- 宠物窗口改为点击「启动」后创建，模型就绪前按钮显示「启动中...」。
- 道具素材改为首次使用时加载，后续重复播放直接复用。
- 安装包体积进一步精简，语言包只保留 `zh-CN` 和 `en-US`，移除重复 Node 依赖和源码映射文件。
- 补充 README 实机演示截图和最新素材贡献者信息。

## 调整

- 移除 Ollama 支持；旧配置会自动切换回云端 API 模式，并清除本地模型名和 Ollama 地址。
- 调整 AI 服务商预设顺序，DeepSeek 与小米 MiMo 更易找到。

## 说明

- 本次更新不改变云端 API 的现有配置和用户数据。
- 当前 Windows 安装包未配置商业代码签名，首次运行时可能出现 SmartScreen「未知发布者」提示。
